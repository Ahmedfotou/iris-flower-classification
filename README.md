# Iris Flower Species Classification

A beginner machine learning project that classifies the species of an Iris flower based on its measurements (sepal and petal length/width).

## What This Project Does
The model takes 4 measurements of a flower (sepal length, sepal width, petal length, petal width) and predicts which of 3 species it belongs to:
- Setosa
- Versicolor
- Virginica

## Tech Stack
- Python
- scikit-learn
- pandas

## Project Pipeline
1. Load the Iris dataset (150 samples)
2. Split the data into training (80%) and testing (20%) sets
3. Train a Decision Tree Classifier
4. Evaluate the model's accuracy on the test set
5. Use the model to predict the species of a new flower

## Result
Model accuracy: **100%** on the test set

## How to Run
```bash
pip install scikit-learn pandas
python iris_classifier.py
```
